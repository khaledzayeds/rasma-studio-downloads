## تحميل التطبيق

[تحميل آخر إصدار لويندوز 64 بت](https://github.com/khaledzayeds/rasma-studio-downloads/releases/latest/download/Rasma-Studio-windows-x64.zip)

1. نزّل ملف ZIP وفك الضغط بالكامل.
2. شغّل `Rasma Studio.exe` من المجلد بعد فك الضغط.
3. احتفظ بجميع الملفات بجانب التطبيق؛ لا تنقل ملف EXE وحده.

الإصدار الحالي 0.11.0 نسخة تجريبية تحت التطوير. الإغلاق من محرر الفيديو بزر × إغلاق أو Esc. التركيز الحالي على تطوير الوايت بورد. لا يوجد مثبت تلقائي أو تحديث تلقائي في هذا الإصدار.
